This is the source tree root for Android Developer Tools, including Android Studio and the Android Gradle Plugin.

When being asked to review code, use these instructions:
Critique my current git comitted change in this repository. Look for
bugs, missing test cases, redundant or duplicated code, unnecessary
comments, and anything else you think could be improved. Finding bugs
or mistakes is the most important thing; look carefully.

When adding functionality, consider adding the test first, making sure
it fails, and then add the functionality, and finally make sure the
tests pass. This way, we're sure the tests are really covering the
broken scenario.

After fixing a bug, always add a regression unit test too (unless one
already exists and was failing).

If adding clever code, make sure you leave a clarifying comment.

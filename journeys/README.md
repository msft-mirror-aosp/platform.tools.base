Developers working on the `journeys` project are recommended to use one of the following Bazel plugins for development:

*   [Bazel plugin](https://plugins.jetbrains.com/plugin/22977-bazel)
*   [Bazel for IntelliJ](https://plugins.jetbrains.com/plugin/8609-bazel-for-intellij)

These plugins provide better integration with the Bazel build system used in this project.
